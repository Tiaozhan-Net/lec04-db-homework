# 常见问题

## 中文变成问号 / 乱码

文件必须存成 **UTF-8 无 BOM**。

- VS Code：右下角点编码 → `Save with Encoding` → `UTF-8`；
- 记事本：另存为 → 编码选 `UTF-8`（不要「带 BOM 的 UTF-8」）；
- 命令行导入时加 `--default-character-set=utf8mb4`。

Workbench 里如果表里原本是中文、显示成问号，先检查导入时有没有带 `--default-character-set`。

## `mysql` 不是内部或外部命令

装 MySQL 时没加进 PATH。两条路：

1. 用完整路径：

   ```powershell
   & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p
   ```

2. 把 `C:\Program Files\MySQL\MySQL Server 8.0\bin` 加到系统 PATH，然后重开终端。

嫌麻烦就用 Workbench，不用命令行。

## 3306 端口被占用 / 连不上

```powershell
netstat -ano | findstr :3306
```

- **有输出**：已经有一个 MySQL 在 3306 上跑，可能就是你装的那个，直接连它；
- **没输出**：服务没起来。检查一下：

```powershell
Get-Service | Where-Object { $_.Name -like "MySQL*" }
```

看到 `MySQL80` 是 `Stopped` 的话：

```powershell
Start-Service MySQL80
```

（需要管理员权限的 PowerShell）

## 忘了 root 密码

MySQL Installer 里有 **Reconfigure**，可以重设 root 密码。
或者干脆卸载重装，练习库的数据重灌一遍就行（`db/99_reset.sql`）。

## Workbench 常用操作

| 想干什么 | 怎么做 |
| --- | --- |
| 切换到某个库 | 左边 **Schemas** 里双击库名，变粗体就是选中了 |
| 跑一个 `.sql` 文件 | `File → Open SQL Script`，然后点 ⚡（Execute All） |
| 只跑选中的几行 | 选中，点 ⚡ 旁边那个「执行选中语句」的按钮 |
| 看表 | 左边展开 schema → Tables → 右键 `Select Rows` |
| 报错了 | 下面 **Output** 面板，红字第一行就是错误码 |

## PowerShell 里 `<` 重定向不生效

PowerShell 不支持 `mysql ... < file.sql`。用下面任意一种：

```powershell
# 1. 用 -e "source ..."（推荐，要在仓库根目录）
mysql -u root -p -e "source db/00_clean.sql" hw_clean

# 2. 交给 cmd 执行
cmd /c "mysql -u root -p hw_clean < db\00_clean.sql"
```

## 改了文件，但 CI 没跑

只有改动 `submissions/**` 才会触发评测。只改了模板或者题面，不会跑。

## 分数没变

- 推送之后再等 1–2 分钟；
- PR 页面 → Checks → 点进 autograde → 看是不是还在跑；
- 确认 `git push` 成功了（`git status` 看有没有未推送的提交）；
- 只改自己目录，别的改动会被 Guard 拦下。
