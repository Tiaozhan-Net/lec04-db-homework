# 常见问题

## 中文变成问号 / 乱码

文件必须存成 **UTF-8 无 BOM**。

- VS Code：右下角点编码 → `Save with Encoding` → `UTF-8`；
- 记事本：另存为 → 编码选 `UTF-8`（不要「带 BOM 的 UTF-8」）；
- 命令行导入时加 `--default-character-set=utf8mb4`。

## `mysql` 不是内部或外部命令

装了 MySQL 但没加进 PATH。用完整路径，或者重新跑安装程序勾上「Add to PATH」。
用 Docker 的话不用管这个，直接用 `docker compose exec mysql mysql ...`。

## 3306 端口被占用

```powershell
netstat -ano | findstr :3306
```

如果本机已经有 MySQL 在跑，Docker 那个起不来。两条路：

1. 用本机的 MySQL，不启 Docker 的；
2. 改 `docker-compose.yml` 里的端口（比如 `3307:3306`），但评测脚本的 `MYSQL_PORT` 也要跟着改。

## 容器一直是 `starting`

第一次初始化要 30–60 秒。超过两分钟还不行：

```powershell
docker compose logs mysql
```

看最后几行。常见原因是磁盘满了，或者 3306 被占用。

## PowerShell 里 `<` 重定向不生效

PowerShell 不支持 `mysql ... < file.sql` 这种写法。用下面任意一种：

```powershell
# 1. 用 -e "source ..."（推荐，要在仓库根目录）
mysql -u root -p -e "source db/00_clean.sql" hw_clean

# 2. 交给 cmd 执行
cmd /c "mysql -u root -p hw_clean < db\00_clean.sql"
```

## 改了文件，但 CI 没跑

只有改动 `submissions/**` 才会触发评测。只改了模板或者题面，不会跑。

## 分数没变

- 推送之后再等 30 秒；
- PR 页面 → Checks → 点进 autograde → 看是不是还在跑；
- 确认 `git push` 成功了（`git status` 看有没有未推送的提交）；
- 只改自己目录，别的改动会被拦。

## `docker compose` 提示不认识这个命令

Docker Desktop 版本太老。升级到带 Compose V2 的版本，或者把命令换成 `docker-compose`。
