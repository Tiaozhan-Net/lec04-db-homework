# 环境与本地评测

课前已经装好 MySQL 8.0，版本要求 8.0.x：推荐 8.0.44（和评测环境一致），最低 8.0.16（第 4 部分要用 `CHECK`，第 5 部分要用函数索引）。本地还需要 **Python 3.10+** 来跑评测脚本；不需要 Docker。

## 1. 确认 MySQL 版本

在 PowerShell 里运行：

```powershell
mysql --version
```

如果提示找不到命令，用完整路径：

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" --version
```

也可以把 MySQL 的 `bin` 目录加进 PATH。进入 `mysql` 后，`SELECT VERSION();` 应该显示 8.0.x。

## 2. Python 和评测依赖

评测脚本需要 Python 3.10 或更高版本。确认：

```powershell
python --version
python -m pip --version
```

如果 `python` 找不到，试试 `py -3 --version`，后面的命令也用 `py -3` 代替 `python`。没有 Python 的话，去 python.org 装 3.10+，安装时勾选 **Add Python to PATH**。

在仓库根目录安装依赖：

```powershell
python -m pip install -r grader/requirements.txt
```

## 3. 配置 MySQL 连接

评测脚本从环境变量读取连接信息，默认值是：

| 变量 | 默认值 |
| --- | --- |
| `MYSQL_HOST` | `127.0.0.1` |
| `MYSQL_PORT` | `3306` |
| `MYSQL_USER` | `root` |
| `MYSQL_PASSWORD` | 空 |

如果 root 有密码，在 PowerShell 里设置：

```powershell
$env:MYSQL_PASSWORD = "你的 root 密码"
```

这个设置只对当前 PowerShell 窗口有效；换窗口或重启后要重新设置。用户名、端口不是默认值时，同样设置 `MYSQL_USER`、`MYSQL_PORT`。

评测会反复建/删 `hw_p*` 库，使用的账号需要有建库权限；按默认的 root 即可。

## 4. 建练习库

在仓库根目录执行：

```powershell
mysql -u root -p --default-character-set=utf8mb4 -e "source db/99_reset.sql"
```

它会建好三个库，并灌入前两份数据：

| 库 | 表 | 内容 |
| --- | --- | --- |
| `hw_clean` | `members` | 14 行规范数据，已有约束 |
| `hw_legacy` | `members` | 28 行脏数据，全列可空、无约束 |
| `hw_bonus` | `members` | 先建空库，加分题再灌 20 万行 |

`source` 用的是相对路径，所以命令必须在仓库根目录执行。PowerShell 不支持 `mysql ... < 文件`，用上面的 `-e "source ..."` 写法。

## 5. 数据与表结构

`members` 的业务字段和标准格式：

| 字段 | 标准 | 例子 |
| --- | --- | --- |
| `student_id` | 8 位数字 | `20230001` |
| `name` | 非空，前后不留空格 | `张三` |
| `class_name` | 四位年份 + `-` + 一位班号 | `2023-1` |
| `major` | `计算机科学与技术` / `软件工程` / `数据科学与大数据技术` | `软件工程` |
| `score` | 0 到 100，两位小数 | `88.00` |
| `joined_at` | `YYYY-MM-DD HH:MM:SS` | `2025-09-01 08:00:00` |
| `deleted_at` | 第 5 部分新增；活跃为 `NULL`，取消后是时间 | `2025-10-01 09:30:00.000` |

三份数据文件：

| 文件 | 内容 | 本地库 |
| --- | --- | --- |
| `db/00_clean.sql` | 14 行规范数据，带约束 | `hw_clean` |
| `db/01_legacy.sql` | 28 行脏数据，无约束 | `hw_legacy` |
| `db/02_big.sql` | 20 万行，加分题用 | `hw_bonus` |

评测用的是另一份数据：字段和脏数据种类相同，人名、学号、分数不同。不要把某一行的结果写死到 SQL 里。

## 6. 三分钟自检

```sql
SELECT VERSION();                                -- 8.0.x
SELECT @@sql_mode;                               -- 要有 STRICT_TRANS_TABLES
SHOW VARIABLES LIKE 'character_set_database';    -- utf8mb4
```

`sql_mode` 里没有 `STRICT_TRANS_TABLES`，第 4 部分的 `1364` 就不会报出来。MySQL 8.0 默认是严格模式，一般不用改。

Python 依赖：

```powershell
python -c "import pymysql, cryptography; print('ok')"
```

## 7. 重做某一部分

每部分末尾都有「重置本部分」，里面是本部分的完整命令。第 1 部分的 DML 会改数据；第 4 部分的 `constraints.sql`、第 5 部分的 `05a` 和 `05c`、加分的 `b2_indexes.sql` 都不能直接重复执行。重做时按对应部分末尾的「重置本部分」来。

## 8. 本地评测

先把模板复制到 `submissions/<你的用户名>/`（见[提交与评测](01-提交与评测.md)），然后在仓库根目录运行：

```powershell
python grader/run.py --part 1 --user <你的 GitHub 用户名>
```

`--part` 可以是 `1`、`2`、`3`、`4`、`5`、`bonus`、`all`，也可以写 `1,2`。输出是一张分数表，看到本部分满分就说明通过；有 ❌ 的项，按“说明”列改。

评测会新建 `hw_p1_dml`、`hw_p3`、`hw_p4` 等临时库，不会改你的 `hw_clean` / `hw_legacy`；加分会重建 `hw_bonus`。想清掉这些库：

```powershell
mysql -u root -p --default-character-set=utf8mb4 -e "source db/99_cleanup.sql"
```

注意：`99_cleanup.sql` 会删掉作业用到的 `hw_*` 库，包括练习库、`hw_bonus` 和评测临时库；之后要重新跑 `db/99_reset.sql`。

## 9. 命令行用法

在仓库根目录进入某个库：

```powershell
mysql -u root -p --default-character-set=utf8mb4 hw_legacy
```

进入后可以直接执行 SQL，也可以用 `source` 跑文件：

```text
USE hw_legacy;
source db/01_legacy.sql
source submissions/<你的用户名>/part3/clean.sql
SELECT * FROM members LIMIT 10;
SHOW CREATE TABLE members;
\G
\c
\q
```

交互式可以用 `USE` 切库；提交的 `.sql` 里不要写 `USE`，评测会在自己的库里执行。`source` 是 mysql 客户端的命令，后面不要加分号；路径从仓库根目录算。

也可以不进入交互模式，直接跑一条命令：

```powershell
mysql -u root -p --default-character-set=utf8mb4 -e "source 文件" 库名
```

写 SQL 用任意文本编辑器，文件保存成 **UTF-8 无 BOM**。中文专业名、姓名写进文件再执行，不要在 PowerShell 里手敲。

## 10. 常见环境问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `mysql` 不是内部或外部命令 | 没配 PATH | 用完整路径，或把 `bin` 加进 PATH |
| `Access denied for user 'root'` | 密码不对 / 没设 `MYSQL_PASSWORD` | 重设环境变量；确认用户名、端口 |
| `Can't connect to MySQL server` | MySQL 没启动 / 端口不对 | 启动 Windows 服务；确认 3306 |
| `ModuleNotFoundError: No module named 'pymysql'` | 没装依赖 | `python -m pip install -r grader/requirements.txt` |
| `找不到提交目录` | 没有复制模板 / `--user` 和目录名不一致 | 按 docs/01 复制到 `submissions/<用户名>/` |
| `Unknown database 'hw_legacy'` | 没建库，或脚本里写了 `USE` | 跑 `db/99_reset.sql`；提交的 SQL 里不要写 `USE` |

更多报错码见[常见问题](02-常见问题.md)。
