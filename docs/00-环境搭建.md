# 环境搭建

只要 **MySQL 8.0.36**。不要 5.7，也不要 8.4 —— 版本不一样，报错码和执行计划会对不上。

两条路选一条。

---

## 路线 A：Docker（推荐）

1. 装 Docker Desktop（Windows 需要 WSL2），启动它，等左下角变绿；
2. 在仓库根目录执行：

   ```powershell
   docker compose up -d mysql
   ```

3. 等它就绪（第一次要 30–60 秒）：

   ```powershell
   docker compose ps
   ```

   看到 `db-hw-mysql` 那一行是 `(healthy)` 就可以了。

4. 自检：

   ```powershell
   docker compose exec mysql mysql -uroot -phw_root -e "SELECT VERSION();"
   ```

---

## 路线 B：原生安装

Windows 装 MySQL Community Server **8.0.36**，安装时把 MySQL Shell / 命令行客户端勾上。

装完在 PowerShell 里：

```powershell
mysql --version
```

能出版本号就行。后面所有 `docker compose exec mysql mysql ...` 换成 `mysql -u root -p ...` 即可。

---

## 建练习库（可选）

**跑评测不需要这一步**，评测脚本会自己建库灌数据。
只有想手动 `SELECT` 看看脏数据长什么样的时候才需要。

```powershell
docker compose run --rm grader sh -c "mysql -h mysql -uroot -phw_root -e 'source db/99_reset.sql'"
```

会建两个库：

- `hw_clean`：14 行规范数据；
- `hw_legacy`：28 行脏数据。

原生安装的话，在仓库根目录：

```powershell
mysql -u root -p --default-character-set=utf8mb4 -e "source db/99_reset.sql"
```

加分题的 20 万行（慢，几十秒）：

```powershell
docker compose run --rm grader sh -c "mysql -h mysql -uroot -phw_root -e 'source db/02_big.sql' hw_bonus"
```

---

## 三条自检

```sql
SELECT VERSION();                                -- 应该是 8.0.36
SELECT @@sql_mode;                               -- 里面要有 STRICT_TRANS_TABLES
SHOW VARIABLES LIKE 'character_set_database';    -- utf8mb4
```

`sql_mode` 缺了 `STRICT_TRANS_TABLES` 的话，第 4 部分的 `1364` 不会报出来。
本地口径要和评测一致，Docker 那套已经配好了。

---

## 本地跑评测

```powershell
docker compose run --rm grader python grader/run.py --part 1 --user 你的用户名
```

第一次会构建镜像（装 Python 依赖），等一两分钟。
之后每次都是几秒到几十秒。

`--part` 可以写 `1` `2` `3` `4` `5` `bonus` `all`，也可以 `1,2`。
