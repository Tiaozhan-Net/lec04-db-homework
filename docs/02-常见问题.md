# 常见问题

## 报错码速查

| 错误码 | MySQL 说什么 | 意思 | 怎么办 |
| ---: | --- | --- | --- |
| `1049` | `Unknown database 'hw_legacy'` | 库不存在，或脚本里写了 `USE` | 本地练手先跑 `db/99_reset.sql`；提交的 SQL 里删掉 `USE`，评测会在自己的库执行 |
| `1054` | `Unknown column 'xxx' in 'field list'` | 列名写错 | 对照 `docs/00` 的字段表；列名用反引号或直接写，不要用单引号 |
| `1062` | `Duplicate entry 'xxx' for key 'uk_student_id'` | 这个值已经存在，撞上唯一索引 | 换一个学号；或者先查一下有没有这条 |
| `1048` | `Column 'name' cannot be null` | 这一列不允许 `NULL` | 给一个合法值 |
| `1364` | `Field 'name' doesn't have a default value` | 这列没有默认值，又没写它 | 把该列的列名和值补上 |
| `3819` | `Check constraint 'chk_members_xxx' is violated` | `CHECK` 规则没通过 | 看约束名：分数越界、姓名空、学号不是 8 位、专业不在白名单、班级格式不对 |
| `1064` | `You have an error in your SQL syntax` | 语法错 | 常见于 `ALTER COLUMN x SET NOT NULL`，MySQL 要用 `MODIFY COLUMN` |
| `1060` | `Duplicate column name 'deleted_at'` | 列已经加过了 | 从 `db/01_legacy.sql` 重新开始，`05a` 不能重复执行 |
| `1061` | `Duplicate key name 'uk_student_id'` | 索引已经建过了 | 从 `db/01_legacy.sql` 重新开始，`constraints.sql` 不能重复执行 |
| `1093` | `You can't specify target table 'members' for update in FROM clause` | `UPDATE`/`DELETE` 里直接子查询了同一张表 | 把子查询包成派生表：`DELETE m FROM members m JOIN (SELECT ... FROM members) t ON ...` |
| `1136` | `Column count doesn't match value count at row 1` | 批量 `INSERT` 的列数和值的个数不一致 | 数一下列名和每组 `VALUES` 的个数 |
| `1292` | `Truncated incorrect datetime value` | 字符串转 `DATETIME` 失败 | 第 3 部分的日期没洗干净，先统一成 `YYYY-MM-DD HH:MM:SS` 再做第 4 部分 |
| `1366` | `Incorrect string value` | 字符集不对，常见于中文 | 文件存成 UTF-8 无 BOM；命令行加 `--default-character-set=utf8mb4` |
| `1406` | `Data too long for column 'xxx'` | 值比列定义长 | 检查列长度，或者少写了空格；`name` 是 `VARCHAR(32)`，GitHub 用户名超过 32 个字符时联系老师 |

`1292` 只在本地出现：评测时第 4 部分跑在已经洗好的数据上。

## 中文乱码

文件保存成 **UTF-8 无 BOM**。

- VS Code：右下角点编码，选 `Save with Encoding` → `UTF-8`；
- 记事本：另存为，编码选 `UTF-8`；
- 命令行导入时带 `--default-character-set=utf8mb4`。

## 在命令行里试，再写进文件

在仓库根目录：

```powershell
mysql -u root -p --default-character-set=utf8mb4 hw_clean
```

```sql
mysql> SELECT student_id, score FROM members WHERE score >= 85 ORDER BY score DESC;
mysql> SELECT * FROM members LIMIT 10;
mysql> SHOW CREATE TABLE members;
mysql> \G      -- 上一条竖排显示
mysql> \c      -- 放弃正在写的半条语句
mysql> source submissions/<你的用户名>/part1/02_q1.sql
mysql> \q
```

改文件、`source` 一遍，是主要循环。判分只读文件，所以最后要让文件本身跑通。报错会直接打印在终端里，第一行就是错误码。

想在控制台留个底，用 `tee`：

```sql
mysql> tee C:\temp\try.sql
mysql> SELECT ...;
mysql> notee
```

敲过的语句和结果都会写进文件，把结果和 `mysql>` 提示符删掉就是能提交的 SQL。

中文值写进文件再 `source`。cmd 和 PowerShell 默认是 GBK，手敲中文容易变问号或报 `1366`。

## 重复实验前怎么重置

每部分末尾都有「重置本部分」，按那里的命令执行。第 1 部分的 DML、第 4 部分的 `constraints.sql`、第 5 部分的 `05a` 和 `05c`、加分的 `b2_indexes.sql` 都不能直接重复执行；重做时按对应部分末尾的「重置本部分」来。

整个环境想清空：

```powershell
mysql -u root -p --default-character-set=utf8mb4 -e "source db/99_cleanup.sql"
```

只删作业用到的 `hw_*` 库，别的不动。之后跑 `db/99_reset.sql` 重新建。

## 改了文件，CI 没跑

只有改动 `submissions/**` 才会触发评测。改模板、改题面不会跑。

## 分数没变

- 推送之后再等一到两分钟；
- PR 页面 → Checks → 点进 autograde，看是不是还在跑；
- `git status` 确认提交已经推上去；
- 只改自己目录，改了别处会被拦下，整份不评分。

## 本地评测报错

| 现象 | 处理 |
| --- | --- |
| `Access denied for user 'root'` | 在 PowerShell 里设置 `$env:MYSQL_PASSWORD = "你的密码"`，再跑 |
| `Can't connect to MySQL server` | 确认 MySQL 服务已启动、端口是 3306 |
| `ModuleNotFoundError: No module named 'pymysql'` | `python -m pip install -r grader/requirements.txt` |
| `找不到提交目录` | 先按 `docs/01` 把模板复制到 `submissions/<用户名>/`，`--user` 要和目录名一致 |
