# 提交与评测

## 1. fork 一份

打开仓库页面，右上角 **Fork**。
之后所有操作都在你自己的 fork 上做。

## 2. 建分支

分支名就用你的 GitHub 用户名，好认：

```powershell
git checkout -b 你的用户名
```

## 3. 复制模板

下面复制指令或者自己在资源管理器右键复制

```powershell
New-Item -ItemType Directory -Force submissions/你的用户名
Copy-Item -Recurse homework/templates/part1 submissions/你的用户名/
Copy-Item -Recurse homework/templates/part2 submissions/你的用户名/
```

只复制你要做的部分。目录名必须是你的 GitHub 用户名（大小写不敏感）。

最后长这样：

```text
submissions/你的用户名/
├─ part1/01_dml.sql ...
├─ part2/q1_dup.sql ...
└─ part3/clean.sql
```

## 4. 写 SQL

Workbench 里选好库（左边双击 schema 变粗体），新建查询窗口，写完点 ⚡ 就能跑。
文件存成 **UTF-8 无 BOM**。

本地想先对答案的话，见 [00-环境搭建.md](00-环境搭建.md) 第 4 节。
**没装 Docker、没装 Python 都不影响交作业** —— 判分在 GitHub 上跑。

## 5. push、发 PR

```powershell
git add submissions/你的用户名
git commit -m "hw: 你的用户名"
git push -u origin 你的用户名
```

然后回 GitHub 点 **Compare & pull request**：

- 标题：`hw: 你的用户名`
- 描述里的清单勾一下就行

## 6. 看分数

PR 页面往下拉，**Checks → autograde → Summary**。

第一张表是每个部分各多少分，下面是每个部分的明细：

| 项目 | 结果 | 说明 | 得分 |
| --- | --- | --- | ---: |
| DML 新增一条 | ✅ | 学号 20239001 已写入 | 5 / 5 |
| Q1 条件 + 排序 + 截断 | ❌ | 第 3 行不对：应为 (张三, 92.00)，实际 (赵六, 92.00) | 0 / 3 |

说明列会写清「应为多少、实际多少」，照着改。

改完再 push 一次，会自动重跑。**分数以最后一次为准**，PR 里的历史记录不用管。
没做的部分会是 0 分，不影响其他部分。

## 会被拦住的情况

| 情况 | 结果 |
| --- | --- |
| 改了 `submissions/` 以外的东西（题面、模板、评测脚本） | 直接失败 |
| 目录名和 PR 作者不一致 | 直接失败 |
| 一个 PR 里有两个人的目录 | 直接失败 |
| 单个 `.sql` 超过 64 KB | 直接失败 |
| 出现 `DROP TABLE` / `TRUNCATE` / `INTO OUTFILE` / `LOAD_FILE` | 直接失败 |
| 某个部分没交 | 只有那部分是 0 分，不影响别的部分 |

被拦住的时候 Summary 里会写原因，照着改就行。

## 一次 PR，一份作业

同一个分支可以一直 push，不用关 PR 重开。
