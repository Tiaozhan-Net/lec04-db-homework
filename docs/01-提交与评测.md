# 提交与评测

## 1. fork 一份

打开仓库页面，右上角 **Fork**。之后的操作都在你自己的 fork 上做。

## 2. 建分支

分支名用你的 GitHub 用户名：

```powershell
git checkout -b 你的用户名
```

## 3. 复制模板

```powershell
New-Item -ItemType Directory -Force submissions/你的用户名
Copy-Item -Recurse homework/templates/part1 submissions/你的用户名/
```

只复制要做的部分，目录名必须是你的 GitHub 用户名（大小写不敏感）。

## 4. 写 SQL

在 Workbench 里选中对应的库，打开文件执行，改完再执行一遍。
文件保存为 **UTF-8 无 BOM**。

## 5. 提交 PR

```powershell
git add submissions/你的用户名
git commit -m "hw: 你的用户名"
git push -u origin 你的用户名
```

回 GitHub 点 **Compare & pull request**：

- 标题：`hw: 你的用户名`
- 描述里的清单勾一下

## 6. 看分数

PR 页面往下拉，**Checks → autograde → Summary**。

第一张表是每个部分的得分，下面是明细，说明列会写「应为多少、实际多少」：

| 项目 | 结果 | 说明 | 得分 |
| --- | --- | --- | ---: |
| DML 新增一条 | ✅ | 学号 20239001 已写入 | 5 / 5 |
| Q1 条件 + 排序 + 截断 | ❌ | 第 3 行不对：应为 (张三, 92.00)，实际 (赵六, 92.00) | 0 / 3 |

改完再 push 一次，自动重跑，分数以最后一次为准。

## 会被拦住的情况

| 情况 | 结果 |
| --- | --- |
| 改了 `submissions/` 以外的东西 | 直接失败 |
| 目录名和 PR 作者不一致 | 直接失败 |
| 一个 PR 里有两个人的目录 | 直接失败 |
| 单个 `.sql` 超过 64 KB | 直接失败 |
| 出现 `DROP TABLE`、`TRUNCATE`、`INTO OUTFILE`、`LOAD_FILE` | 直接失败 |
| 某个部分没交 | 只有那部分是 0 分 |
