# 第 2 部分 看得懂：脏数据诊断（20 分）

## 1. 情景

社团上一届的报名表是从 Excel 导进来的，导入的时候没做任何校验。

现在 `hw_legacy.members` 里躺着 28 条记录：同一个学号出现了两三次，有人学号是空的，专业写成「计算机」「计科」「计算机科学」三种，报名时间有的是 `2025/09/01`，有的是 `2025-09-01T08:00:00`。

直接动手清洗是第 3 部分的事。这一部分先做体检：把每一类毛病找出来、数清楚，写成六条查询。

**只查不改。** 文件里出现 `UPDATE`、`DELETE`、`INSERT` 一律 0 分。

这六条查完，你会知道第 3 部分要删多少行、要改哪几列。

## 2. 数据与准备

## 3. 要做什么

六个文件，一个文件一条 `SELECT`。

### 3.1 `q1_dup.sql` 重复学号

一个学号出现两次以上，说明有人重复报名，或者 Excel 里复制粘贴多了。先把这类人找出来，第 3 部分只保留最早的那条。

- 查什么：出现次数大于 1 的学号
- 输出列：`student_id`、`cnt`
- 排序：`cnt DESC, student_id ASC`

学号为空的记录（`NULL`、空串、全空格）不算重复，先排除掉。

> **讲义没讲：** `HAVING` 是 `GROUP BY` 之后对「组」做筛选。`WHERE` 筛的是单行，`HAVING` 筛的是分组结果，`HAVING COUNT(*) > 1` 就是「人数大于 1 的组」。

### 3.2 `q2_name.sql` 姓名不干净

姓名的毛病有三种：整个是 `NULL`、全是空格、前后带空格。第三种最容易被漏掉，因为它显示出来是正常的。

- 输出列：`id`、`name`、`len`
- `len` 写 `CHAR_LENGTH(name) AS len`
- 排序：`id ASC`

这里输出 `name` 的原值，不要顺手 `TRIM`——带空格的行正是要查出来的东西。

> **讲义没讲：** `TRIM(x)` 去掉字符串前后空格；`CHAR_LENGTH(x)` 数的是字符数，不是字节数。

### 3.3 `q3_score.sql` 分数越界

分数是 `DECIMAL(5,2)`，正常范围 0 到 100。表里有负分，也有超过 100 的。

- 输出列：`id`、`score`
- 排序：`id ASC`

`NULL` 不算越界，它属于「没填」，第 3 部分会把它当 0 处理。

### 3.4 `q4_date.sql` 报名时间格式

`joined_at` 是 `VARCHAR`，三种写法混在一起：

```text
2025-09-01 08:00:00
2025/09/01 08:00:00
2025-09-01T08:00:00
```

只认第一种。

- 输出列：`id`、`joined_at`
- 排序：`id ASC`

判断标准写死成「`YYYY-MM-DD HH:MM:SS`」。别用 `STR_TO_DATE` 去猜，它比你想的宽松，`2025-9-1` 也能解析出来。

> **讲义没讲：** `REGEXP` 是正则匹配：`^` 是开头、`$` 是结尾、`[0-9]{4}` 表示「4 位数字」。要整串完全匹配，`^` 和 `$` 都不能省。`NOT REGEXP` 取反，但 `NULL NOT REGEXP ...` 的结果还是 `NULL`，不算真——所以空值要单独用 `IS NULL` 判断。

### 3.5 `q5_whitelist.sql` 专业和班级不在白名单

同一个专业有五六种写法，第 3 部分要把它们统一成三个值：

- `计算机科学与技术`
- `软件工程`
- `数据科学与大数据技术`

班级统一成「四位年份 + `-` + 一位班号」，比如 `2023-1`。

这一条把「专业不在白名单」或者「班级格式不对」的行列出来。

- 输出列：`id`、`major`、`class_name`
- 排序：`id ASC`
- 两个条件之间是「或」：专业不对、班级不对、或者都不对，都要出来

> **讲义没讲：** `NOT IN ('a', 'b')` 是「不在这个列表里」。

### 3.6 `q6_sid.sql` 学号不是 8 位数字

学号的合法形式是 8 位纯数字。表里有 7 位的、9 位的、带字母的、空的。

- 输出列：`id`、`student_id`
- 排序：`id ASC`
- 判断之前先 `TRIM`：前后带空格、去掉后正好 8 位的，不算问题

`TRIM` 和 `REGEXP` 的用法和 3.2、3.4 一样。学号是 8 位数字，写成 `'^[0-9]{8}$'`，`{8}` 表示正好 8 位。
