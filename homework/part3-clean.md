# 第 3 部分 洗得干净：清洗（25 分）

数据：`hw_legacy`（28 行脏数据）。
交一个文件：`part3/clean.sql`，把这张表洗成「能直接加约束」的样子。

只能 `UPDATE` 和 `DELETE`，**原地清洗**：

- 不许 `DROP TABLE`
- 不许 `TRUNCATE`
- 不许建新表再改名、不许 `CREATE TABLE ... AS SELECT`

## 洗完必须满足

### 学号

| 现在 | 洗完 |
| --- | --- |
| 是 `NULL`、空串、或者全是空格 | 这一行删掉 |
| 前后有空格，但去掉空格后是 8 位数字 | 保留，并把学号存成去掉空格后的值 |
| 去掉空格后不是 8 位数字（含字母、7 位、9 位） | 这一行删掉 |

### 姓名

| 现在 | 洗完 |
| --- | --- |
| 前后有空格 | 去掉空格 |
| 是 `NULL`、空串、或者全是空格 | 这一行删掉 |

### 班级

现有三种写法，都是同一个班：

| 现在 | 洗完 |
| --- | --- |
| `2023-1` | `2023-1` |
| `2023级1班` | `2023-1` |
| `2023 1班` | `2023-1` |

规则就是「四位年份 + `-` + 班号」，别的班级同理。洗完只留 `YYYY-N` 这种形式。

### 专业

只留三个值：`计算机科学与技术`、`软件工程`、`数据科学与大数据技术`。

| 现在写成 | 改成 |
| --- | --- |
| `计算机` / `计科` / `计算机科学` | `计算机科学与技术` |
| `软件` / `软工` | `软件工程` |
| `大数据` / `数据科学` | `数据科学与大数据技术` |

### 分数

| 现在 | 洗完 |
| --- | --- |
| `NULL` | `0` |
| 小于 0 | `0` |
| 大于 100 | `100` |
| 0–100 之间 | 不动 |

### 报名时间

统一成 `YYYY-MM-DD HH:MM:SS`。现在是三种写法混着：

```text
2025-09-01 08:00:00
2025/09/01 08:00:00
2025-09-01T08:00:00
```

### 学号重复

同一个学号有多条记录时，**只留报名时间最早的那一条**；
报名时间也一样的，留 `id` 小的那一条。

## 判分

看**洗完以后的表**，不看你的 SQL 长什么样。

| 项目 | 分值 |
| --- | ---: |
| 行数 | 5 |
| 学号 | 5 |
| 姓名 | 4 |
| 班级和专业 | 5 |
| 分数 | 3 |
| 报名时间 | 3 |

每个维度都要**全部行都对**才给分。行数不对的话，其余维度也拿不到。
