# 第 3 部分 洗得干净：清洗（25 分）

## 1. 情景

第 2 部分查出来的毛病，现在要动手治。

这张表洗完必须能直接加约束：学号唯一、六列非空、`joined_at` 能转成 `DATETIME`。哪一类数据没洗到位，第 4 部分加约束时就会失败。

交一个清洗脚本，**只允许 `UPDATE` 和 `DELETE`**，原地洗：

- 不写 `DROP TABLE`
- 不写 `TRUNCATE`
- 不建新表再改名，不写 `CREATE TABLE ... AS SELECT`

## 2. 数据与准备

- 表：`hw_legacy.members`，28 行脏数据，洗完 14 行。
- 第一次（练习库还没建）：

  ```powershell
  mysql -u root -p --default-character-set=utf8mb4 -e "source db/99_reset.sql"
  ```

- 每次重来：

  ```powershell
  mysql -u root -p --default-character-set=utf8mb4 -e "source db/01_legacy.sql" hw_legacy
  ```

字段的标准格式（整份作业都按这个判断）：

| 字段 | 标准 | 例子 |
| --- | --- | --- |
| `student_id` | 8 位数字 | `20230001` |
| `name` | 非空，前后不留空格 | `张三` |

## 3. 要做什么

### 3.1 学号

学号是后面唯一索引和 `CHECK` 的基础，先处理它。

| 现在 | 洗完 |
| --- | --- |
| 是 `NULL`、空串、或者全是空格 | 这一行删掉 |
| 前后有空格，去掉后是 8 位数字 | 保留，并写回去掉空格后的值 |
| 去掉空格后不是 8 位数字（含字母、7 位、9 位） | 这一行删掉 |

「写回」这一步不能省：带着空格存进去，第 4 部分的 `^[0-9]{8}$` 会把它拦下来。

### 3.2 姓名

| 现在 | 洗完 |
| --- | --- |
| 前后有空格 | 去掉空格 |
| 是 `NULL`、空串、或者全是空格 | 这一行删掉 |

`TRIM` 之后再判断是不是空，顺序反了会把全空格的名字留下来。

### 3.3 班级

三种写法指的是同一个班：

| 现在 | 洗完 |
| --- | --- |
| `2023-1` | `2023-1` |
| `2023级1班` | `2023-1` |
| `2023 1班` | `2023-1` |

规则是「四位年份 + `-` + 班号」，其他班级同理。洗完只留 `YYYY-N` 这种形式，因为第 4 部分的 `CHECK` 就按这个写。

> 字符串拼接用 `CONCAT(a, b)`，取左边几个字符用 `LEFT(x, n)`，从某个位置取一段用 `SUBSTRING(x, 起点, 长度)`。

### 3.4 专业

只留三个值：`计算机科学与技术`、`软件工程`、`数据科学与大数据技术`。现在表里是这些写法：

| 现在写成 | 改成 |
| --- | --- |
| `计算机` / `计科` / `计算机科学` | `计算机科学与技术` |
| `软件` / `软工` | `软件工程` |
| `大数据` / `数据科学` | `数据科学与大数据技术` |

> `CASE WHEN 条件 THEN 值 WHEN ... ELSE 值 END` 就是 SQL 里的 if-else，可以直接写在 `SET` 右边或 `SELECT` 里。

### 3.5 分数

| 现在 | 洗完 |
| --- | --- |
| `NULL` | `0` |
| 小于 0 | `0` |
| 大于 100 | `100` |
| 0 到 100 之间 | 不动 |

同一列里三种情况对应两个结果，写成两条 `UPDATE` 更清楚。

### 3.6 报名时间

统一成 `YYYY-MM-DD HH:MM:SS`。现在是三种写法混着：

```text
2025-09-01 08:00:00
2025/09/01 08:00:00
2025-09-01T08:00:00
```

洗完之后，这一列要能直接被 `MODIFY COLUMN ... DATETIME(3)` 转过去，不需要再兜底。

> `STR_TO_DATE(字符串, '%Y-%m-%d %H:%i:%s')` 把字符串按指定格式解析成日期；`DATE_FORMAT(日期, '%Y-%m-%d %H:%i:%s')` 再格式化回字符串；`REPLACE(s, 'a', 'b')` 做字符替换。`%i` 是分钟，不是 `%m`。

### 3.7 学号重复

同一个学号有多条记录时，**只留报名时间最早的那一条**；报名时间也一样的，留 `id` 小的那一条。

> MySQL 不允许在 `DELETE` 的 `WHERE` 里直接子查询同一张表，会报 1093。把这部分包成派生表再 `JOIN`：
>
> ```sql
> DELETE m FROM members m
> JOIN (SELECT ... FROM members GROUP BY ...) d ON d.xxx = m.xxx
> WHERE ...;
> ```
>
> 也可以先把「要保留的 id」放进一张临时表，再 `DELETE ... WHERE id NOT IN (...)`。
